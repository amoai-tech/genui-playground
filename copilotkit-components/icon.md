# Icon

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/icon
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Media
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/icon

## Purpose

A Lucide icon by kebab-case name (for example "arrow-right"), or an A2UI icon name (for example "arrowBack"). Set label when no text next to the icon says what it means.

## API props (from official reference)

| Prop | Official type |
|---|---|
| `name` | `string \| object` |
| `label?` | `string` |
| `size?` | `"sm" \| "md" \| "lg" \| "xl" \| number` |
| `color?` | `string` |
| `strokeWeight?` | `"normal" \| "medium" \| "semibold" \| "bold"` |
| `inline?` | `boolean` |
| `weight?` | `number` |
