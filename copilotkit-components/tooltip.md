# Tooltip

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/tooltip
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Text
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/tooltip

## Purpose

Shows \`content\` when the user points at or focuses \`trigger\`. \`trigger\`: one child id, a Text, Icon or Badge (not a Button or Link). \`content\`: one child id of short text, no links or buttons.

## API props (from official reference)

| Prop | Official type |
|---|---|
| `trigger` | `· single` |
| `content` | `· single` |
