# DateTimeInput

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/date-time-input
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Inputs
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/date-time-input

## Purpose

A date picker, a time picker with enableTime, or both. timeStep (minutes) offers fixed times, e.g. 30 for a booking. The value is ISO 8601. Give it a label.
