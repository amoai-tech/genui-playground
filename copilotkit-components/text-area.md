# TextArea

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/text-area
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Inputs
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/text-area

## Purpose

A multi-line text input. Bind value with { "@path": "/x" } to read what the user typed. Give it a label.
