# Select

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/select
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Inputs
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/select

## Purpose

A dropdown list of options. Bind value with { "@path": "/x" } to read the chosen option. Give it a label.
