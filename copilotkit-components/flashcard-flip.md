# FlashcardFlip

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/flashcard-flip
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Feedback and overlay
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/flashcard-flip

## Purpose

A card that shows the front text. A click or the Enter key flips it to the back text, and again to the front.

## API props (from official reference)

| Prop | Official type |
|---|---|
| `front?` | `string` |
| `back?` | `string` |
| `hint?` | `string` |
