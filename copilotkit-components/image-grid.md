# ImageGrid

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/image-grid
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Composites
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/image-grid

## Purpose

A gallery of images in a grid. A click opens the image full-screen, with arrows to the other images. layout "bento" makes the first image twice as large.

## API props (from official reference)

| Prop | Official type |
|---|---|
| `images?` | `object[]` |
| `columns?` | `number` |
| `gap?` | `number \| string` |
| `layout?` | `"grid" \| "bento"` |
| `aspectRatio?` | `string` |
