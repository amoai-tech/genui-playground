# Caption

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/caption
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Text
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/caption

## Purpose

Small secondary text: a hint under a control, or a label in a Row. \`text\` can have inline markdown.

## API props (from official reference)

| Prop | Official type |
|---|---|
| `text` | `string \| number` |
| `color?` | `string` |
| `size?` | `"sm" \| "md" \| "lg"` |
| `fontWeight?` | `"normal" \| "medium" \| "semibold" \| "bold"` |
| `textAlign?` | `"start" \| "center" \| "end"` |
| `truncate?` | `boolean` |
| `maxLines?` | `number` |
