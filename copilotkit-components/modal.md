# Modal

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/modal
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Feedback and overlay
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/modal

## Purpose

A dialog over the page. A click on the trigger (a Button or a Text) opens the content in the dialog. Escape, the close button or a click on the backdrop closes it.

## API props (from official reference)

| Prop | Official type |
|---|---|
| `title?` | `string` |
| `open?` | `boolean` |
| `maxWidth?` | `number \| string` |
| `weight?` | `number` |
| `trigger` | `· single` |
| `content` | `· single` |
