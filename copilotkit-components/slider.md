# Slider

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/slider
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Inputs
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/slider

## Purpose

A range slider for a number between min and max. Bind value with { "@path": "/x" } to read the number. Give it a label.
