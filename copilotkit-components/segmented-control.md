# SegmentedControl

**Official documentation:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/segmented-control
**Catalog:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog
**Group:** Inputs
**Source page:** https://docs.copilotkit.ai/generative-ui/components/standard-catalog/segmented-control

## Purpose

A row of segments. The user chooses one option. Use it for 2 to 5 short options. Bind value with { "@path": "/x" } to read it.
